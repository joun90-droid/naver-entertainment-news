# 🎬 네이버 연예뉴스 핫토픽 (NAVER Entertain Hot Topic)

네이버 연예뉴스 실시간 랭킹 및 핫토픽(연예가화제, 방송/TV, 영화, 드라마, 뮤직, 해외연예)을 한눈에 조회하고 관리하는 데스크톱 전용 모던 대시보드 프로그램입니다.

---

## 🌟 주요 기능 (Key Features)

1. **실시간 7개 카테고리 기사 수집**:
   - 🔥 **실시간 랭킹** (실시간 많이 본 뉴스 TOP 20)
   - 💥 **연예가 핫토픽** (가장 이슈가 되는 연예 소식)
   - 📺 **방송 · TV** (예능, 교양, TV 프로그램 이슈)
   - 🎬 **영화** (신작 영화, 박스오피스, 배급 소식)
   - 🎭 **드라마** (드라마 캐스팅, 시청률, 비하인드)
   - 🎶 **뮤직** (음원, 음반, 콘서트, 아이돌 소식)
   - 🌐 **해외연예** (할리우드, 글로벌 연예 이슈)

2. **다크 모드 & 고해상도 프리미엄 UI**:
   - 세련된 다크 테마 디자인과 직관적인 탭 카드 레이아웃.
   - 고화질 뉴스 썸네일 이미지 및 비동기 멀티스레딩 로딩 적용.

3. **실시간 뉴스 검색 & 필터링**:
   - 키워드나 언론사 이름 검색 시 실시간 반응 필터링 지원.

4. **상세보기 & 브라우저 연결**:
   - 기사 선택 시 우측 상세 인스펙터 패널에 썸네일, 언론사 태그, 기사 요약본 표시.
   - `🌐 원본 기사 읽기` 클릭 시 기본 웹 브라우저로 네이버 연예뉴스 원본 즉시 이동.
   - `📋 링크 복사`로 기사 URL 클립보드 간편 복사.

5. **⭐ 즐겨찾기 (북마크) 저장 기능**:
   - 관심 있는 핫토픽 기사를 `bookmarks.json`에 저장하여 언제든지 다시 확인.

6. **📥 데이터 내보내기 (TXT / JSON / CSV)**:
   - 현재 조회 중인 연예뉴스 핫토픽 목록을 텍스트, JSON, 또는 Excel/CSV 형식으로 내보내기 지원.

7. **🔄 자동 새로고침 타이머**:
   - 1분, 3분, 5분 단위 자동 갱신 지원.

## 🚀 실행 방법 (How to Run)

### 1. 파이썬으로 실행하기
```bash
python main.py
```

### 2. 배치 파일로 실행하기 (윈도우)
`run.bat` 파일 더블 클릭 실행
